## 적용 대상과 계량 기준

- p1 제1~3조: 빙장·냉동 상태로 판매하는 수산물에 관한 세칙이다. 표기 중량은 **원물만의 중량**이다. 얼음·빙장수·드립·보냉재·포장재와 냉동 상품 표면 빙의(글레이징)는 포함하지 않으며, 포장 전체를 통째로 잰 값과 표기 중량을 직접 비교하지 않는다.
- p1 제4조①~③: 판정 기준은 검정 저울로 출고 시 측정·기록한 **출고 중량**이다. 품목·로트·계량치·시각을 출고 검사 기록에서 대조한다. 수령 중량은 이미 자연감량이 진행된 값이므로 그 자체를 표기 중량과 직접 대조하지 않는다.
- p1 제5조: 해당 로트 출고 중량 기록이 없거나 확인되지 않으면 불이익을 고객에게 돌리지 않고 **표기 중량을 기준으로 판정**한다. 원인 규명을 고객에게 요구하지 않는다. 다른 비교 값까지 없을 때 정상 또는 미달을 자동 확정하라는 뜻으로 확대하지 않는다.
- p2 제6조①~④: 출고부터 수령까지 통상 배송기간(익일 내지 모레)에 생긴 자연감량은 **표기 중량의 3%까지** 인정한다. 수령 후 고객 보관·해동 과정에서 생긴 감량은 이 3%에 해당하지 않는다. 문서는 현 취급 범위를 냉동 갈치·옥돔과 그 빙장 포장으로 설명하고, 품목·포장별 차등 없이 단일 기준을 적용한다고 명시한다.

## 판정 경계와 계산

- p2 제7조①②, p3 제11조: 판매·환불 규정 제6조의 표기 허용오차 5%와 위 자연감량 3%를 합한 **표기 중량 대비 미달 8% 이내는 정상**, **8% 초과는 실제 미달**이다. 8%를 넘는 경우 초과분만이 아니라 **표기 중량 대비 부족분 전체**에 대하여 부분환불(차액환불) 또는 재배송 중 고객이 선택한다.
- 경계 예시: 표기 1,000g에서 판정에 쓸 출고 실측이 920g이면 부족 80g = 정확히 8%로 정상 범위다. 출고 실측이 919g이면 부족 81g = 8.1%이므로, 대조 결과가 확인된 경우 1g이 아니라 81g 전체가 부족분 대상이다. 이 예시는 **출고 기록을 판정 값으로 사용**한 산술 예시이며 고객 수령 사진값 단독을 표기와 비교한 결론이 아니다. 제9조의 기록·대조와 필요 시 재촬영을 거쳐야 한다.
- p2 제7조③ 원문은 **“초과 여부의 계산은 실결제액을 기준으로 한다”**고 적는다. 중량의 8% 초과 여부와 금액 기준 사이의 관계가 문면상 명확하지 않다. 환불 금액의 정확한 산식, 할인·배송비 배분과 반올림은 이 문서만으로 확정하지 않는다. [판매·환불 규정 추출](pending_sources_extracted.md) 제6조②도 부족분 부분환불 또는 재배송을 정하지만 구체 금액 산식을 제시하지 않는다. 부분환불 산식 정본과 해당 문구의 의미를 담당자에게 확인할 필요가 있다.
- p2 제8조: 정상 범위인 경우도 단순히 ‘규정상 정상’으로 끝내지 않고 계량 결과·근거와 빙장수·드립으로 실제 감량이 생기는 사실을 설명한다.

## 접수·대조·재촬영·금지

1. **접수**: p2 제9조①은 중량 미달 주장을 접수하도록 하며 증빙 부족을 이유로 접수 단계에서 반려하지 않는다.
2. **순서**: p2 제9조②는 (1) 상품 상세·라벨의 표기 중량 (2) 해당 로트 출고 기록 (3) 제7조 판정선 (4) 고객 계량치와의 어긋남이 남을 때 제10조 재촬영 순서로 정한다. 고객 저울 사진만으로 단독 판정하지 않는다(제9조③). 이미지라는 이유만으로 신뢰도를 낮추거나 이미지 진위를 감정하지 않는다(제9조④).
3. **재촬영 조건**: p2~3 제10조①~③은 원물, 저울 표시값, 주문번호가 함께 보이는 **사진 1장**을 요청한다. 얼음·빙장수를 따라 버리고 물기를 뺀 원물만 저울에 올리며 포장재·보냉재를 제거한다. 주문번호는 송장 또는 주문내역 화면으로 함께 보이게 한다. 요청 근거는 **대조 결과**이며 조작 의심을 이유로 제시하지 않는다.
4. **불가능 예외**: p3 제10조④는 이미 조리·폐기하는 등 재촬영이 어려우면 출고 중량 기록만으로 판정하고, 재촬영 불가를 거절 사유로 삼지 않는다. 출고 기록도 없는 경우에는 p1 제5조의 표기 중량 기준과 고객 불이익 금지를 별도로 적용한다. 비교에 필요한 정보가 전혀 없는 경우를 자동으로 정상·미달 어느 쪽으로든 단정하지 않는다.
5. **금지**: p3 제12조는 자연감량만을 이유로 접수 없이 거절, 근거 없는 조작·연출 단정이나 암시, 출고 중량 기록을 확인하지 않고 사진만으로 환불 확정, 계량 결과와 다른 값의 응답 생성을 금지한다. p3 제11조는 출고 중량과 고객 계량치가 자연감량으로 설명되지 않는 폭으로 어긋나면 재촬영 후 재판정하도록 한다.

## 고객 응대와 API 연결

- 주문 귀속을 확인한 뒤 해당 주문의 품목·로트와 상세/라벨의 표기 중량, 해당 로트 출고 계량 기록·시점을 조회할 수 있어야 한다. 자연감량의 배송기간 조건과 고객이 제시한 계량 상태를 구분해 기록한다. 서로 어긋나면 판독값을 꾸미지 말고 대조 결과에 근거해 필요한 표준 재촬영을 요청한다.
- 부족 확정 시 고객에게 부족분 전체에 대한 부분환불 또는 재배송 선택을 묻고, 선택에 맞는 요청을 접수한다. 접수 API가 성공해도 환불·재배송 완료를 의미하지 않으므로 접수와 이행 상태를 구분해 안내한다. 위탁 계약 p3 제8조·제13조②에 따라 공급자 확인·내부 정산을 기다리게 하지 않는다([계약 추출](evidence_20261031_extracts.md)).
- 이미지·로트 계량기록·환불/재배송을 읽고 접수할 구체 API 이름과 필드, 실제 호출 가능 여부는 이 작업에서 확인하지 않았다. 문서에 나온 업무 단계만으로 API가 존재하거나 처리가 완료됐다고 가정하지 않는다.
