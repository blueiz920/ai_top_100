# 공개 검증 사례와 인터뷰 연결

출처: https://aitop100.org/contest/docs/test-cases 및 /L-11 (2026-10-31 직접 열람). API 실행은 하지 않음.

## L-11 곰팡이 핀 수박 하자 신고
- 사례: 수령 4일 후 개봉, 꼭지·껍질 곰팡이. 같은 로트 선행 신고 1건, 조사 기록 없음. 고객은 안전을 우선 걱정하고 환불 선택.
- 공개된 처리: 사과, 섭취·신체 이상 확인. 대상 주문에 한해 배송 조회(API-11), 해당 로트/조사/신고 이력 확인(API-03/04/06). 선택한 전액환불 접수(API-29), 별도로 LANE2_HANDOFF 담당자 확인 요청(API-35). 접수 결과·이관번호·회신 기한 안내.
- 정책 설명: 명백한 위생 위해 하자는 섭취 중단·폐기, 반송 요구 없이 재배송 또는 전액환불. 정본인 판매 환불 규정집은 아직 미확보.
- 사례 전용 값: 로트 KD-WTM-370624-03, 환불액 34900. 이 값은 일반 정책이나 다른 고객에 적용하지 않는다.
- 미확인: 로트 품질·출하 기준, 조사·공급자 확인 절차, 환불 규정 원문, 이관 회신 기한. 공개 사례만으로 비공개 평가 전체를 가정하지 않는다.

## 인물별 확인할 정보 (질문 미전송)
- 박수복: 출하 전 품질·선별 기록/기준 자료, 직접 관찰과 보고 구분. 환불 승인 기준은 묻지 않는다.
- 이민준: 판매 환불 규정집과 하자 접수 절차.
- 고길동: 동일 로트 복수 신고와 안전 이관의 판단·절차·회신 기한.
- 인터뷰 결과를 상품 안내 → 증거/대상 확인 → 정책 판단 → 액션 → 고객 안내에 연결한다.

## 질문 우선순위 재검토
수박 10통 중 6통 사례의 현장 확인은 필요하지만 해당 사실만 확인하면 전반적인 CS 지식 확보가 좁아진다. 우선 박수복의 품질·출하 기준 및 기록 자료를 확보하고 구체 사례를 검증 질문으로 사용하자는 제안. 사용자 승인 전 질문 전송 금지.
