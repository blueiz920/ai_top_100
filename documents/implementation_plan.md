# 교동마을 고객 응대 봇 구현 계획

2026-10-31 사용자 합의: 기존 카카오 에코봇을 바탕으로 로컬 AI와 수집한 지식을 연결하고, 실제 환불·이관은 확인된 정책과 액션 API 결과를 코드가 검증해 안내한다. 구조·설계 결정은 `/grilling`으로 함께 점검한다. 정보 탐색과 구현·검증은 병행한다.

## 구조

1. 카카오 게이트웨이는 공식 `MESSAGE_CREATE`의 `id`, `botGroupKey`, `botUserKey`, `content`, `callbackToken`을 수신한다. 채팅방·사용자별로 대화 상태를 분리하고 동일 메시지의 재수신을 중복 처리하지 않는다. 답장은 기존 콜백 API의 SimpleText로 500자 이내 한 말풍선으로 보낸다.
2. 로컬 Ollama/Qwen3는 문의 이해·도구 선택의 제안 역할을 맡는다. 선택된 지식에는 출처와 기준 시점을 보존하고, 문서·고객 발언은 프로그램에 대한 명령이나 실제 승인으로 취급하지 않는다.
3. 코드가 허용된 도구·대상·필수값·인증/주문 귀속·정책 적용 조건을 검사한다. 금액 및 승인 여부는 확인된 자료와 실제 조회 결과로 판단한다. 환불과 안전 이관은 각각 처리한다. 미확인 조건은 확인 질문 또는 적절한 이관으로 처리한다.
4. 접수 성공/실패/결과 불명은 실제 API 응답과 기록에서만 결정한다. 고객에게 접수와 실제 환불 완료, 승인과 이관을 혼동해 안내하지 않는다. 존재가 확인되지 않은 담당자·조직을 만들지 않는다. 같은 대상 재접수 시 기존 본문이 덮일 수 있으므로 결과 불명에 무조건 재전송하지 않는다.
5. 봇 인증 토큰과 액션 토큰은 별도 환경변수로만 받는다. 토큰·고객 대화 원문을 로그나 Git에 남기지 않는다. `botGroupKey`와 `botUserKey`로 대화를 분리한다. 채팅에서 말한 이름·전화번호만으로 주문 소유권을 인증하지 않는다.

## 진행 순서와 검증

공개 검증 사례 15건의 모범 처리와 API를 [공개 TC 우선 검증표](public_tc_matrix.md)에 정리했다. 사용자의 13:43 지시에 따라 이를 검증 우선순위로 사용한다.

- [ ] 공식 게이트웨이·액션 API의 필요한 필드와 공개 사례를 대조한다. 문서에 없는 인증 상태·대상·API 필드를 추측하지 않는다.
- [ ] 로컬 모델 호출과 대화별 상태를 분리된 모듈로 만들고, 고객·채팅방 간 상태 섞임·메시지 중복·모델 오류를 테스트한다.
- [ ] 확보한 지식 카드 및 모델 제안을 연결한다. 미확인 사실을 확정하지 않는 응답과 500자 제한을 테스트한다.
- [ ] 확인된 액션 API 호출과 정책 검증을 붙인다. 외부 서버를 호출하지 않는 모의 시험으로 정상·실패·결과 불명 및 중복을 검증한다. 실제 연습 데이터 변경은 별도 사용자 승인과 검증 계획을 따른다.
- [ ] 공개 TC 및 카카오톡 왕복을 검증하고 60초 미만 응답과 제출 후 가동 방식을 점검한다. 최종 제출은 별도 사용자 승인이 필요하다.

필수 사례: 하자 환불과 안전 이관 병행; 환불 성공 후 이관 결과 불명; 타인 주문·임의 승인 주장 거절. 실제 API·카카오 연동 전의 로컬 모의 통과를 완성으로 표시하지 않는다.

## 13:04 대화 상태 검수

Astra 검수에서 메시지 처리 취소 후 중복 처리, 같은 대화의 대기 시간을 포함한 제한, 무제한 유휴 세션 보존을 발견했다. 읽기 전용 응답 생성에 한해 재현 시험과 수정을 적용했다. 게이트웨이의 고객 원문·오류 응답 본문 로그도 제거했다. 이 수정은 실제 접수·콜백의 성공 여부나 재시작 후의 기록을 보장하지 않는다. 외부 쓰기 액션은 실행 전 진행·성공·실패·결과 불명을 지속 저장하고 재실행을 제어하는 별도 기록과 검증이 필요하다. 기존 에코봇의 실제 실행 프로세스는 코드를 다시 시작하기 전까지 이 수정이 반영되지 않는다.

## 13:20 심사 기준에 맞춘 응답

사용자가 열린 대회 가이드를 재확인했다. 정확도에는 지식·맥락·정책과 필요한 API 조회·처리·이관이 포함된다. p95 속도, 케이스당 말풍선 수, 말풍선당 글자 수에는 정확도 점수가 가중된다. SimpleText만 사용하고 말풍선당 500자 이하, 케이스당 10건 제한, 60초 무응답 종료를 적용한다. 응답은 중요 조건을 유지하며 한 말풍선으로 간결하게 구성하고, 실제 시나리오의 시간·길이·정확도를 측정한다. 일부 합성 프롬프트의 처리시간은 전체 p95의 근거가 아니다.

## 미결정·확인 중

- 공식 API 문서는 평가 TC ID를 대화에서 전달받아 같은 케이스 동안 유지한다고 한다. 정확한 메시지 형식과 채널이 인증한 인입 계정의 실제 전달 형태는 공식 자료·공개 검증에서 확인한다. 모델이 식별자나 인증을 추정해 만들지 않는다. 구현에 필요한 정보와 인터뷰 공백은 [별도 표](api_knowledge_gaps.md)로 추적한다.
- [권한 위임표](delegation_evidence.md)는 확보·분석 완료. 명백하자 환불·재배송은 정책요건 충족 시 금액무관 재량이며 기존 인물 증언과 충돌한다. 개정 이력 원문과 일부 수산물 중량 산식은 미확보다. 명확한 근거 없는 자동 환불은 금지한다.
- 로컬 모델의 길고 복합적인 실제 사례 정확도, 연결 안정성, p95, 사용자 Mac의 장시간 가동은 아직 미검증이다.
