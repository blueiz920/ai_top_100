- §5.3 제목은 **33건**이나 표에는 고유 SKU 행이 **34건** 있다. 2037-06-30 기준 상태는 판매중 19, 예약 접수 3, 시즌 종료 11, 일시 품절 1이다. 표의 구체 행과 요약 제목 차이를 그대로 남기며, 34가 정식 승인된 전체 SKU 수라고 임의로 확정하지 않는다.

## 표시 중량과 수산 특칙의 적용 경계

- 카탈로그 §4.2: **‘N kg 이상’은 절대 하한**으로 표기값 아래를 ±5% 오차로 정당화하지 않는다. 정량표기 ‘N kg’에는 판매·환불 규정 제6조의 ±5%를 적용하며, 개수 판매 등 중량 미표기에는 중량 기준선이 없다. 개별 고객이 실제로 본 표기와 출고 계량을 확인한다.
- 같은 §4.2는 **수산물 자연감량은 별도 수산 중량·자연감량 세칙 소관이며 표기오차와 합산**한다고 명시한다. [수산 세칙](fish_weight_evidence.md) p1 제4~5조·p2 제6~7조는 출고 기록을 기준으로, 통상 배송 중 자연감량 3%와 정량 표기오차 5%를 합쳐 미달 8% 이내를 정상 범위로 정한다. 8% 초과 시 부족분 전체의 부분환불 또는 재배송을 고객이 선택한다. 고객 수령 사진값만 표기와 직접 비교하지 않는다.
- **현재 카탈로그의 수산 3개 SKU(GAL-STD-1, OKD-STD-1, OKD-GIFT-2)는 모두 정량표기**다(§5.3). 따라서 현재 나열된 수산 SKU에는 이상표기의 절대 하한과 수산 8% 기준이 같은 라벨에 직접 충돌하지 않는다. 다만 향후 수산물에 ‘이상’ 표기가 붙는 경우 §4.2의 절대 하한과 수산 세칙 §7의 합산 규정 사이 명시된 예외·우선순위가 없다. 8%를 자동 적용하거나 둘을 임의로 조합하지 말고 실제 고객 표기와 소관 기준을 확인한다. 위탁 계약 p1 제3조② 및 판매·환불 규정 제19조는 충돌 시 고객 보호와 유리한 처리를 원칙으로 제시한다.

## 등급·당도·입수·가격

- §4.4: 특·상·보통은 정상 등급이다. B급은 외관 흠·비규격이 있으나 품질 이상이 없는 별도 `-B` SKU로 할인 판매하며 재고는 해당 SKU를 조회한다. **열과·기형 등 규격 외는 출하 제외**이고 예약분 정상 수량에 세지 않는다. 등급 혼합 주문은 등급별 수량·단가를 분리한다. 외관 흠이 있다는 사실만으로 실제 부패·하자 신고를 거절하는 뜻은 아니다.
- §4.1·§6.1~6.2: 당도보장 표기는 **WTM-SEL-8의 11브릭스 이상, HGL-SEL-5의 12브릭스 이상** 두 줄이다. 실제 로트 측정값을 그 SKU의 고객 표기와 대조한다. 하우스감귤 선별 라인은 12가 기준이며 일반 출고 배제선 11을 보장선으로 바꾸면 안 된다. 수치 보장 없는 일반 라인의 주관적 단맛 불만만으로 수치 보장 위반을 확정하지 않는다. 다른 하자 가능성은 별도 확인한다.
- §5.3·§6.2: `HGL-SEL-5`는 **28과·특·12브릭스 보장**, `HGL-STD-5`는 **31과·상·당도보장 없음**, `HGL-STD-10`은 **60과·상·당도보장 없음**이다. 부분 하자 비율의 분모는 같은 SKU의 고정 입수와 라벨을 우선 확인하고, 개수 비고정 상품은 실물 개체수를 확인한다. 실제 수량이 미확인이면 [부분환불 세칙](partial_refund_evidence.md)의 표기 중량·표준 중량에 의한 추정 등 순서를 따르고 추정임을 알린다.
- §5.3은 정상가 숫자가 있는 행과 `—`인 행이 섞여 있다. §5.3의 `—`는 값 미보유이지 무료·0원이 아니다. 정상가 정본은 별도 가격 정책 시트이며 프로모션 적용가는 프로모션 원장과 실제 주문 결제를 확인한다. 예시로 §6.1 WTM 선별·일반 8kg은 사본상 각 27,900원이고 §6.2 HGL 선별 5kg 30,000원·일반 5kg 24,000원이다. 시점이 다른 고객 주문의 실제 결제액을 이 숫자로 대체하지 않는다.
- §6 서문은 선별과 일반의 당도 표기만 다르다고 설명하지만, 실제 §6.2 HGL 행은 **입수·과중·등급·가격도 다르다**. 전체 속성이 동일하다는 식으로 단순화하지 않는다.

## 다른 근거와의 차이·미확인

- §5.1의 봄감자 시즌은 **5~7월**이나 같은 문서 §9는 **03-02 봄감자 수확 개시, 05-18 시즌 마감 임박**이라고 적고, 기존 기상 운영 기준 DOC-001 p1 제2조①은 **봄감자 3~5월**을 예시로 든다. 표현 범위·시즌 정의의 차이인지 불일치인지 확정할 수 없다. 농산 시즌 정본인 「교동마을 농산 시즌 캘린더」를 확인한다. 감자 저장분이 판매중이라는 §5.3의 06-30 상태와 생감자 시즌은 별개다.
- 애플망고 §5.1 시즌 **6~8월**은 DOC-001의 제철 **6~7월·예약 출고 8월 초까지**와 기간 표현이 다르다. 판매·출고 기간과 제철 기간이 다른 것인지 정본 캘린더로 확인한다. 06-30 망고 SKU 판매중과 산지 작황 기록의 예약 출고 지연·재개 미확정은 서로 다른 상태이며 개별 주문의 실제 출고 가능일을 확인해야 한다.
- `NGL-GRN-3` 청귤은 별도 풋과 규격·예약 접수이며 성숙 감귤로 임의 대체하지 않는다(§5.3). `GAL-STD-1`은 06-30 일시 품절, `OKD-STD-1`은 판매중이며, 기존 조업·입고 기록의 06-30 비성어기 갈치 재고 소진·옥돔 정상과 일치한다. 실제 수량·재입고·발송일은 이 카탈로그에 없다.
- 수박 표기 비교를 설명하면서 §6은 같은 조건에서 당도표기만 다르다고 하나 실제 WTM 선별·일반 SKU의 등급은 특 대 상·보통이다. 실제 표에 적힌 등급 차이와 소비자 표기 여부를 각각 보존한다. 각주가 참조하는 일부 절 번호와 제목·건수는 문서 내부에서 어긋나므로 이 분석은 **실제 표제와 SKU 행**을 기준으로 인용한다.

## 고객 응대와 API 연결

- 상품·입수·등급·보장 문구는 해당 SKU와 고객 라벨/상세로 확인하고, 실제 수량·판매 가능성은 재고 조회, 개별 고객의 출고·결제·하자 판단은 해당 주문·로트 조회와 연결한다. 카탈로그의 대체 SKU 목록은 후보이지 해당 대체 상품의 현재 재고나 고객 동의를 증명하지 않는다.
- 기준일 판매 상태와 품절 원인·실시간 수량·계약 주문 상태를 별도 데이터로 보존한다. ‘예약 접수’를 즉시 출고로, ‘판매중’을 개별 주문 출고 완료로 바꾸지 않는다.
- §7의 공개 정보는 품목·라인·원산지·품종·규격·입수·등급·보장 여부·보관·후숙·시즌·판매 상태·정상가·대안이다. SKU 코드와 위탁 여부는 고객이 물은 범위에서만 안내한다. 매입가·정산가·수수료율·생산자 실명과 연락처 등 내부·제3자 정보는 공개하지 않는다. 생산자 지정은 허용되지 않는다.
- 실제 액션 API의 SKU 상세·재고·주문·로트 필드와 호출 결과는 본 문서 분석에서 검증하지 않았다. 적용 규정·현재 상태·고객 선택을 확인한 뒤 API를 호출하고 접수와 실제 처리 완료를 구분한다. 농산 시즌 정본, 고객 라벨 원문, 가격 정책 시트, 이상표기 수산물 특칙의 경계는 미확인으로 남긴다.
