## 1. 홍보 주장·할인 문의

### 원문상 운영 기준

- PM PDF p1 §2, p2 §7: 코드 등록 여부 → **결제 완료 시각**의 기간 → 대상 품목 → 회원 자격 → 사람 단위 한도 → 중복 허용 순서로 확인한다. 전부 충족했는데 적용되지 않았다면 업체 귀책으로 취소·재결제 없이 차액 부분환불이라고 기재한다. 실제 주문·회원·사용 이력의 조회와 환불 접수 가능 여부는 별도 API 확인이 필요하다.
- PM PDF p1 §5: 주문당 할인 코드는 1개다. 공구·단골·신규가입·추천 리워드 사이에는 중복이 안 되지만 보상 쿠폰과 적립금은 할인 코드와 병용할 수 있다. 보상 쿠폰은 주문당 1장이다. 유리한 할인 코드 1개를 선택하되 실제 자격·한도를 먼저 확인한다.
- PM HTML §4·§9, PP 상태 기록: 2037-06-30 사본 기준 `SUBAK15`는 수박 한정 15%, 전체 회원, 1인 1회, 결제 완료 기준 06-26~07-03 24:00까지 유효다. `GAMJA10`은 05-09, `MANGO10`은 06-12에 종료했다. 코드 상태는 날짜가 지난 사본으로 현재 유효라고 단정하지 않는다(PM PDF p1 §2⑤).
- PM HTML §4·§4-1: `DANGOL5`는 조합원 재구매 5% 정식 혜택이다. ‘겨울 가격/단골 특별가’라는 별도 원장 행이 없다는 사실은 DANGOL5가 없다는 뜻이 아니다. `REFER5000`은 피추천인의 가입뿐 아니라 첫 구매의 구매확정 후 추천인에게 발급된다. 상태 판정은 등록·발급·사용 이력으로 한다.
- PP `A07_promotion-rules.docx` 제1조③④: 코드 조건의 정본은 원장이다. ‘발행 사실 없음’을 확인할 때는 원장과 **라이브·게시물 아카이브**를 모두 조회하고 결과를 상담 기록에 남긴다. PP 상태 기록이 20% 코드와 무료배송 포함 코드·게시물의 발행 사실이 없다고 적고 PM HTML §4-1도 20% 코드 부재를 적지만, 별도 아카이브 원문은 이 분석에서 확보하지 못했다. 따라서 그 아카이브까지 실제 조회한 것으로 기록하거나 발언 자체가 없었다고 단정하지 않는다.

## 2. 배송 단계·결항

### 규정과 특정 시점 사실

- TC p1 제2조1호·제3조①③: 집하는 택배사가 출고지 물품을 인수해 운송을 시작하는 단계다. 배송지 변경·취소 가부를 가르는 집하 시각은 집하 스캔 기록이며, 스캔과 출고지 인계에 대한 진술이 다르면 스캔을 기준으로 한다. 집하 전에는 변경·취소 가능하고 이후 일반 변경은 불가하다. 반송 후 재배송 주소는 변경 요청을 받을 수 있는 예외가 있다(TC p2 제10조③).
- TC p1 제3조②: 송장 등록 후 배송사 조회 반영에 통상 3~5시간이 걸릴 수 있다. 송장번호가 있다는 사실은 집하 완료를 뜻하지 않는다.
- SR `5. 운송편 결항 상세 (2037-06-05 태풍 구간)`!A6:C12·A14: 애플망고 예약분은 06-04 14:00 수확, 18:30 포장; 06-05 09:10 송장 등록, 11:40 결항 통보·집하 취소; 06-06 산지 냉장 대기; 06-07 15:00 간선 재개; 06-08 09:00 집하 재개·밀린 물량 순차 처리다. 06-05 11:40 이후부터 06-08 09:00 전은 송장 등록·집하 전 상태다. 이는 해당 사건에 대한 기록이며 개별 주문에 실제 집하 스캔이 있었는지는 별도 조회해야 한다.
- SR `3. 기록 확인 기준`!B4:B10 및 `4. 기상·운송 이력`!A5:F15: 예보 행의 `—`는 미확정이지 정상 또는 결항이 아니다. 작황·조업·운송은 별도 확인하고 간선 재개와 집하 재개도 구분한다. 06-30 기록에는 특보 없음·집하/간선 정상이라고 기재되나, 이것이 특정 주문의 배송 완료나 도착일 보장은 아니다. 화면 사진 C54_01~05를 검토했으며 각 화면은 해당 XLSX 행을 다시 보여준다.
- TC p2 제6~8조: 보관 조건이 다른 농산·냉동 수산의 합배송은 제한된다. 동일 수령지의 출고 전 복수 주문은 합포장할 수 있고 절감된 초과 배송비는 환불 또는 정산한다. 고객 요청 분할배송은 최초 출고일부터 7일 이내, 최대 3회차, 회차별 비용이 생길 수 있다.
- TC p2 제10~12조: 고객 귀책 반송의 재배송비는 고객 부담이 원칙이나 재량 범위의 분담이 가능하다. 배송 중 파손의 판매자·운송사 간 정산은 고객 처리와 분리한다. 배송완료인데 미수령인 건은 조사 접수하고 고객 과실이 아니면 우선 재발송한다. 접수와 실제 환불·재배송 완료는 다르다.

## 3. 수산물 인도·품질 책임

- SC p1 제2조2호, p2 제5조·제7조: **갯마을 출하장에서 지정 차량 적재 완료**가 계약상 인도다. 인도 시 공급자가 냉동 원물 심부온도 -18℃ 이하를 확인·기록하며, 확인 뒤 발생한 온도 이탈은 교동 조합 책임 구간으로 본다. 집하·간선 인계라는 운송 구간 명칭은 이 인도 시점을 바꾸지 않는다. 온도·인계 기록이 없거나 이탈 구간을 특정하지 못하면 내부 부담을 균분하지만 고객 구제 지연·축소 사유는 되지 않는다.
- 기존 DOC-007 콜드체인 기록의 특정 옥돔 사례와 대조하면 적재 완료 및 기록된 인도 후 운송 중 이탈이라는 시간 구분과 일치한다([기존 근거](new_sources_evidence.md), [셀별 전사](new_sources_cells.md)). 이는 그 주문의 실제 보상 완료를 입증하지 않는다.
- SC p3 제8·12조, p4 제17조: 고객 문의·하자 접수·환불·재배송 창구는 교동이다. 공급자 확인이나 내부 분담을 이유로 고객 처리를 미루지 않고, 내부 수수료·정산·분담 비율은 고객 안내 항목이 아니다. 농산과 위탁 수산이 한 주문에 있어도 환불·정산은 상품별로 분리한다.
- SC p1 제3조③·p2 제4조④는 수산물 자연감량·허용오차를 별도 「수산물 중량·자연감량 허용치(빙장수·드립)」 제6·7조에 위임한다. 원문 미확보이므로 일반 농산물 중량 기준을 해당 수산물에 임의 적용하지 않는다.
