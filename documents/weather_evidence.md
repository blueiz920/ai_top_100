## 출처 우선순위·신선도
- 갱신 매 영업일 1회, 주말/공휴일 사실은 다음 영업일에 반영하고 그동안 기준일은 앞당기지 않음(DOC-002 '개요'!B9, '제2부 별지'!A3).
- —는 그 시점 확정 사실 없음. 정상/영향 없음과 구별(DOC-002 '제2부 별지'!B9).
- 농산 작황 정본: 교동마을 작황·재해 기록. 조업·입고 정본: 갯마을 조업·입고 기록. 결항·집하 정본: 시원배송 결항·집하 기록. 별지와 충돌 시 소관 기록 우선(DOC-001 p2, DOC-002 '제2부 별지'!A24).
- 기준일 이후 조업·배편·출고 가능 여부는 현장 확인 필요. 별지로 현재 단정 금지(같은 시트 A26, DOC-001 p2).
- 민준 증언과의 관계: 기준 문서와 실제 현장 상태를 구분하라는 질문 8 답변을 문서로 뒷받침함. 새 인물의 실제 정보는 아직 미확보.

## 후속 인터뷰 후보 (전송 미승인)
- 박수복: 제공 정보 범위 확인 후 망고 출고 재개 가능 시점, 수박 정상 6통/부족 4통 후속 상태, 농산 정본 자료 요청.
- 홍이장: 제공 정보 범위 확인 후 현재 조업·갈치 예약 충당량, 수산 정본 자료 요청.
- 고길동: 제공 정보 범위 확인 후 박수복 소개 및 배송 담당자/계약서 소관 확인.
- 김청년: 제공 정보 범위 확인 후 홍이장 소개 요청.
- API 매핑은 문서 명세를 확인한 뒤 별도 추가한다. 이 문서로 액션 실행 권한을 추정하지 않는다.

## 12:46 농산 정본 추가 확인
- 박수복이 제공한 [DOC-049 작황·재해 기록](originals/crop_disaster_20370630.xlsx)을 확보했다. [시트·셀 전사](crop_disaster_cells.md), [정본과 기존 별지 대조](crop_disaster_evidence.md)를 참고한다.
- 기존 F08~F11은 해당 정본 `4. 작황·재해 이력!A13:G16`과 내용상 일치한다. 수박 피해는 DOC-049의 06-28 행에서 산지 확인되었고 DOC-002는 이를 06-29 행에 요약했다. 06-30 신규 영향 없음은 망고 출고 재개 또는 수박 예약분 보충 완료를 뜻하지 않는다.
- 위 표의 과거 ‘정본 요청’ 제안은 자료 확보 전의 이력이다. 후속 확인은 현재 개별 주문·실제 재개 상태에 집중한다.

## 13:42 농산 시즌 정본 확보
- [DOC-061 농산 시즌 캘린더](crop_season_evidence.md)는 월별 사이클과 2037 실제 전환일을 따로 둔다. 이전 제철 예시 옆 ‘정본 미확보’는 확보 전 상태다.
- 감자 일반 사이클 봄 5~7월과 2037 실제 봄 수확 개시 03-02·05-18 시즌 마감 임박의 차이는 원인이 명시되지 않는다. 망고는 4~5월 예약, 6월 성, 7~8월 말이며 8월 신규 예약을 자동 중단하지 않는다. 해당 월의 시즌과 고객 주문 출고·재고는 별도다.
