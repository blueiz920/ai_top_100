# 액션 API와 응대 지식의 연결·공백

2026-10-31, 사용자가 연 사이드브라우저에서 공식 액션 API의 OpenAPI 문서와 공개 TC를 확인했다. 기능이 명세에 있다는 것과 정책상 호출할 수 있다는 것은 구분한다. 실제 API를 호출하거나 데이터를 변경한 것은 아니다.

| 고객 업무 | 문서상 필요한 API·정보 | 확보된 근거 | 부족한 정보와 다음 확인 |
|---|---|---|---|
| 상품 규격·보관·판매 | API-01 상품, API-02 검색, API-21 재고. SKU·실제 판매 상태와 보관 조건 | [SKU 카탈로그](sku_catalog_evidence.md), [수산 공급표](fish_supply_evidence.md) | 카탈로그는 2037-06-30 스냅샷이며 재고 수량은 없다. 실제 API 조회 결과와 구분한다. 서로 다른 SKU를 모델이 임의로 합치지 않는다. |
| 할인 주문의 일부 환불 | API-07 주문·API-18 결제와 개별 SKU 실결제액, 손상 개수, 승인 기준·고객 선택 | [부분환불 산식](partial_refund_evidence.md), [위임표](delegation_evidence.md) | 공식 `Orders.items`에는 SKU·상품명·수량·단가가 있고 `Orders.amount`는 주문 전체 금액이다. SKU별 할인·쿠폰·적립 배분 필드는 이 응답에 없다. 결제 응답도 주문 단위 금액이므로 다른 근거 없이 한 SKU의 실결제액을 추정하지 않는다. 민준·홍보라·고길동 모두 배분법을 모른다고 답했다([13:41 확인](../interviews/batch_1342.md)). |
| 주문·배송 정보 | API-07 주문의 `member_id`, API-11 주문별 배송, 인증된 인입 계정 | [개인정보·운영 근거](pending_sources_evidence.md), 공식 공개 L-23 | 로그인과 주문 귀속은 별도다. 실제 카카오 평가 대화에서 시스템 인증 계정이 어떻게 표시되는지 아직 미확인이다. 주문번호, 카카오 사용자 키, 고객이 말한 이름·연락처를 쇼핑몰 인증으로 가정하지 않는다. |
| 안전 신고와 하자 환불 | API-35 이관, API-29 환불. 각각 해당 요건·실제 접수 결과 | [3레인 절차](escalation_evidence.md), [위임표](delegation_evidence.md), 공개 L-11 | SAFE 별도 가이드와 민준 부재 시 승인 대행 경로는 미확보. 안전 초기 안내는 지체하지 않고, 근거 없이 실제 접수나 승인을 주장하지 않는다. |
| 평가 중 API 헤더 | `X-Aitop100-Test-Case-Id` | [액션 API 공통 규약](action_api_basics.md) | 공식 문서는 평가의 공개·비공개 TC ID를 **대화에서 전달받고 동일 케이스 동안 유지**하라고 한다. 정확한 전달 문자열·시스템 출처 구분은 미확인이다. ID를 생성하거나 공개 ID로 고정해 평가에 사용하지 않는다. |
| 수산물 이상 표기와 중량 | API-01 표기 중량, 로트·출고 기록, 수산물 자연감량 규정 | [SKU 카탈로그](sku_catalog_evidence.md), [수산 중량 세칙](fish_weight_evidence.md) | 현재 수산 SKU는 정량 표기다. 장래 수산 SKU가 ‘이상’ 하한 표시라면 하한 원칙과 수산 자연감량 특칙의 관계를 확인해야 한다. 문서만으로 우선순위를 추측하지 않는다. |
| 현금영수증 용도 | API-32 접수와 소득공제·지출증빙 유형 | [발행 기준](receipt_issuance_evidence.md) §2, [민준 14:33 증언](../interviews/batch_1434.md) | 유형을 담당자에게 전달하고 반영을 확인하는 접수 기록·절차는 민준도 모른다. 번호만으로 유형이나 발행 완료를 추정하지 않는다. API 지원 여부는 별도 확인 사항이다. |
| 할인 코드와 보상 쿠폰 | SUBAK15·CARE 쿠폰의 결제액 계산 | [홍보라 14:34 증언](../interviews/batch_1434.md), 프로모션 마스터 | 홍보라는 중복 가능 조건을 설명했으나 차감 전후 계산 순서와 원 단위 처리는 모른다고 밝혔다. 확인되지 않은 최종 금액을 임의 계산하지 않는다. |

새 API 연동 중 위와 같은 공백이 나오면 담당 문서·인터뷰를 확인하고, 부족하면 고객 문의와 연결한 질문을 해당 관계자에게 제안한다. 인터뷰 메시지는 대상·문구별 사용자 승인 후 보낸다.

공식 대회 FAQ의 운영사무국 문의 경로는 `aitop100@kakaoimpact.org`다. 실제 평가 TC ID와 인증된 인입 계정의 전달 필드·표기 예시는 대회 운영 측에 확인할 대상이다. 문의 메시지를 작성·발송한 것은 아니다. 출처: https://aitop100.org/ FAQ.
